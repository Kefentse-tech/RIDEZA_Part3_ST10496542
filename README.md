 RIDEZA Website Project

 Part 1: Basic HTML Structure

The webpage had a simple HTML structure with minimal style.

Part 2: CSS Styling and Responsive Design

To make every page look cleaner, more polished, and consistent, CSS styling was added.

 Navigation Bar

Part 1:** There was little styling and basic navigation.

Improvement of Part 2:** Improved alignment, hover effects, white text, spacing, and a black navigation bar.

 Typography

Part 1: The browser's default text styling was mostly used on the pages.

Improvement of Part 2: Arial was used as the primary font, and the size of the headings and paragraphs was changed for easier reading.

 Page Layout

Part 1: A straightforward layout with little spacing was used to present the content.

Improvement of Part 2: To make the content easier to read and visually organised, sections, rounded corners, padding, margins, and shadows were added.

 Services Page

Part 1: Basic HTML content was used to display services.

Improvement of Part 2: Individual service cards with backgrounds, hover effects, and spacing were added.

About Us Page

Part 1: The goals, objectives, and values were displayed in a simple manner.

Improvement of Part 2: The page's overall layout was enhanced, and styled value cards were added.

 Booking Page

Part 1: The reservation form featured simple input fields in HTML.

Improvement of Part 2:The form's labels, input fields, dropdown menus, text area, and button were all styled.

Contact Page

Part 1: Basic HTML formatting was used to display contact information.

Improvement of Part 2: Styled location cards were added, and the form and contact sections' layout was enhanced.

Gallery Page

Part 1: Pictures were shown in an unorganised manner.

Improvement of Part 2: Using CSS Grid, a responsive gallery was made with one image per row on smaller screens and two images per row on larger screens.

 Buttons and Links

Part 1: Links and buttons were poorly styled.

**Improvement of Part 2: Enhanced link appearance and styled buttons with hover effects were added.

 Images and Logo

Part 1: The RIDEZA logo and images were present, but their styling was inconsistent.

Improvement of Part 2: The size and placement of the images were enhanced, and the navigation logo was made uniform throughout the website.

 Responsive Design

Part 1: The website was primarily created for desktop viewing.

Improvement of Part 2: A responsive media query was added to make the navigation, gallery, text, and layout adapt to smaller screens, such as mobile devices.

 User Experience

Part 1: Although the pages were navigable, the design was very simple.

Improvement of Part 2: Usability, visual organisation, spacing, readability, and navigation were enhanced.

 Home Page

Part 1: The home page had simple sections and basic content.

Improvement of Part 2:Styled feature cards for RIDEZA's various services and advantages were added.

 Part 3: Enhancing Functionality and SEO

 JavaScript Functionality

JavaScript was added to improve the functionality and user experience of the RIDEZA website.

 Booking Form Validation

Part 2: The booking form contained HTML input fields and styling.

Improvement of Part 3: JavaScript validation was added to check that users complete the required fields, enter a valid South African phone number, and select a date that is not in the past. A success message is displayed when the form is completed correctly.

 Contact Form Validation

Part 2: The contact form allowed users to enter their contact information and message.

Improvement of Part 3: JavaScript validation was added to check that the required fields are completed and that the email address is entered in a valid format. A confirmation message is displayed after successful validation.

Services Search

Part 2: The Services page displayed the available RIDEZA services.

Improvement of Part 3: A JavaScript search function was added to allow users to search for services. Matching services are displayed as users type, and a message appears when no matching services are found.

 Back to Top Button

Part 2: Users had to scroll manually to return to the top of the webpage.

Improvement of Part 3: A Back to Top button was added to the Home page. JavaScript allows users to return smoothly to the top of the page when the button is clicked.

 Search Engine Optimisation (SEO)

Part 2: The website mainly focused on its visual appearance, layout, and responsive design.

Improvement of Part 3: SEO techniques were added to improve the website's visibility and help search engines understand the content of each page.

The following improvements were made:

- Unique page titles were added to the HTML pages.
- Meta descriptions were added to describe the content of each webpage.
- The page titles and descriptions were written according to the content of each page.
- The HTML language attribute was included to identify the website's language.
- Semantic HTML elements such as header, nav, main, section, and footer were used to organise the webpage content.

 HTML Forms and Validation

The Booking and Contact pages contain HTML forms that allow users to enter their information.

 Booking Form

- Input fields were provided for the user's name, phone number, pickup location, destination, ride type, number of passengers, date, and time.
- HTML validation attributes were added to help ensure that the required information is entered.
- JavaScript validation checks the phone number format and prevents users from selecting a past date.

Contact Form

- Input fields were provided for the user's name, email address, and message.
- Required fields were added to ensure that users complete the necessary information.
- JavaScript validation checks that the email address is entered in the correct format.

Both forms display confirmation messages when the information passes validation.

 Gallery Functionality

Part 2: The Gallery page displayed images using a responsive CSS Grid layout.

Improvement of Part 3:JavaScript functionality was added to allow users to click on gallery images to view an enlarged version. A close button was included so users can close the enlarged image. Users can also close the image by clicking outside it or pressing the Escape key.

The lightbox functionality was tested to ensure that images display correctly in an enlarged overlay.
